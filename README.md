# HEALTHCARE-ANALYTICS
🏥 Healthcare Analytics Dashboard

📊 Project Overview

This project is an interactive Healthcare Analytics Dashboard designed to analyze hospital operations, patient demographics, billing, medical conditions, admissions, insurance providers, and healthcare outcomes.

The dashboard transforms raw healthcare data into meaningful visual insights that can help healthcare organizations understand patient trends, hospital performance, billing patterns, and operational metrics.

---

🎯 Project Objectives

- Analyze overall patient and hospital performance
- Monitor total billing and room utilization
- Understand patient demographics
- Analyze admissions by type
- Compare patient test results
- Identify billing trends across medications and hospitals
- Analyze insurance provider distribution
- Track patient volume over time
- Understand medical-condition distribution
- Create an interactive and user-friendly healthcare reporting solution

---

🛠️ Tools & Technologies

- Power BI — Dashboard development & visualization
- Power Query — Data cleaning and transformation
- DAX — Measures and calculated metrics
- Microsoft Excel — Data preparation
- Data Visualization — Interactive charts, KPIs, slicers and tables

---

📌 Dashboard Features

KPI Cards

The dashboard provides key healthcare metrics including:

- 💰 Total Billing Amount
- 🏨 Total Rooms
- 👨‍⚕️ Total Doctors
- 👥 Average Patient Age
- 🩸 Total Patients by Blood Type

Interactive Filters

Users can dynamically filter the dashboard using:

- Date of Admission
- Discharge Date
- Gender
- Admission Type
- Blood Type

Visualizations

The dashboard includes:

- Billing Amount by Medication
- Patients by Test Results
- Doctors by Medical Condition
- Billing Amount by Hospital
- Patient Trends over Time
- Patients by Insurance Provider
- Blood Type Analysis
- Medical Condition Distribution
- Hospital and Doctor Analysis

---

📈 Key Insights

The dashboard enables analysis of questions such as:

1. Which medications generate the highest billing amount?
2. Which hospitals contribute the most to total billing?
3. How are patients distributed across test-result categories?
4. Which medical conditions have the highest number of patients?
5. Which insurance providers cover the largest patient populations?
6. How does patient volume change over time?
7. How do admission types vary across the patient population?
8. What is the overall distribution of patients by blood type and gender?
